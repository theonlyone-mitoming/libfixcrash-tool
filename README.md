# LibFixCrash

## Purpose
This library helps fix crash errors (segmentation faults, aborts) for applications in a testing environment.

## Scope of Use
- For research, debugging, and learning purposes only.

- NOT to be used for any malicious, destructive, or illegal activities.

## Platforms
- Linux ARM64 / x86_64
- Android NDK (if applicable)

## How to Use
Download the `libfixcrash.zip` file from the **Releases** folder and extract it to get `libfixcrash.so`.
